# Календарь звонков

Домен сервиса бронирования тайм-слотов для звонков (аналог Calendly / Cal.com).

## Language

### Бронирование

**Слот (Slot)**:
Вычисляемый 15-минутный интервал внутри расписания доступности владельца. Слоты не хранятся — выводятся из Availability и существующих броней; начало брони всегда на 15-минутной сетке.
_Avoid_: ячейка календаря, интервал

**Тип встречи (Event Type)**:
Шаблон встречи, который публикует владелец: название, описание и длительность (15/30/60 минут). Из типа встречи и Availability вычисляются бронируемые слоты.
_Avoid_: событие, event

**Бронь (Booking)**:
Факт записи гостя в конкретный слот. Начало брони — момент её slotStart; занимает время, требуемое длительностью типа встречи.
_Avoid_: запись, резерв

**Доступность (Availability)**:
Расписание владельца: дни недели (1–7, ISO) и окно времени (startTime–endTime), в котором возможно бронирование.
_Avoid_: расписание, график, working hours

### Страницы

**Главная страница (Landing)**:
Статическая страница `/`: рассказывает о сервисе и ведёт на страницу записи. Не показывает живых данных и не содержит логики бронирования.
_Avoid_: лендинг, домашняя страница, home page

**Страница записи (Booking Page)**:
Страница `/book`, где Гость выбирает Тип встречи и слот и оставляет Бронь. Сюда ведёт Главная страница.
_Avoid_: страница бронирования, каталог

### Роли

**Владелец (Owner)**:
Единственный пользователь сервиса, управляющий типами встреч, доступностью и бронями. Аутентификации нет — владелец один.
_Avoid_: админ, пользователь, host

**Гость (Guest)**:
Человек, бронирующий слот по публичной ссылке. Не регистрируется; идентифицируется именем и email в брони.
_Avoid_: клиент, участник, visitor
