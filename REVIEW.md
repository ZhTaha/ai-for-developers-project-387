# Критерии ревью

Критерии ревью изменений календаря звонков. Их читает человек-ревьюер и
авторевью (`.github/workflows/pr-review.yml`): изменение сверяется с
критериями ниже. Форматирование, стиль и именование не проверяются.

## Правила бронирования

1. **Занятое время недоступно.** Слот, пересекающийся с существующей
   Бронью с учётом длительности Типа встречи, показывается
   заблокированным, а запись на него отклоняется сервером с кодом `409`.
2. **Слоты считаются, а не хранятся.** Список слотов на дату выводится
   из Availability и существующих Броней: только дни недели Availability,
   внутри окна `startTime`–`endTime`, начало на 15-минутной сетке;
   Бронь без `durationMinutes` считается 15-минутной.
3. **Окно записи — 14 дней** от «сегодня» в часовом поясе Владельца.
   Дата вне окна, не из дней Availability или с началом вне окна
   времени отклоняется сервером с кодом `409`.
4. **Длительность Типа встречи уважается.** Встреча занимает
   `durationMinutes`: выход последней встречи дня за `endTime` допустим,
   пересечение с соседней встречей — нет.
5. **Прошедшие слоты недоступны.** Слот, начавшийся к текущему моменту в
   часовом поясе Владельца (граница включительная: начало ровно сейчас —
   уже прошедший), показывается заблокированным с признаком `past`, а
   запись на него отклоняется сервером с кодом `409`. Признак считается
   на сервере — страница не сравнивает время по клиентским часам.

## Контракт и сборка

6. Изменения REST API внесены в `typespec/main.tsp` вместе с
   `src/server.js` и тестами; коды и тела ответов совпадают с
   `typespec/generated/openapi.json`; `mise run check` зелёный.
7. Генерируемые пути (`typespec/generated/openapi.json`,
   `public/generated-api.js`) не правятся руками — только через
   `mise run generate`.
8. Фронтенд обращается к API через сгенерированный SDK: новый прямой
   `fetch` к `/api` — замечание.
9. Коммиты — Conventional Commits.
10. Проверки детерминированы: тесты не зависят от дня недели и текущего
    времени запуска (выбор даты — от Availability и окна формы,
    границы времени — на фиксированном `now`); правило с часовыми
    поясами проверено на поясе Владельца, а не на предположении о
    смещении UTC.

## Поведение интерфейса

11. Тема разговора (комментарий Гостя) выводится в строке Брони как
    текст; пустая тема и тема из пробелов не выводится вовсе — строка
    совпадает со строкой без темы.
12. Ошибка сервера показывается Гостю без ложного подтверждения записи;
    после неё введённые данные формы не теряются.

## Формат замечания

- Замечание = **файл, строка, условие ошибки, последствие**.
- Если дефектов по критериям нет — написать об этом прямо.
- Форматирование, стиль и именование не проверять.
